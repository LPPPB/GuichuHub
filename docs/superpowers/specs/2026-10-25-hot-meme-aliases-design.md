# 热梗写法归一与别名聚合

本次承接用户“继续”确认的方案，仅修改热梗榜，基于本地提交 4942b6e。

## 规则

- 先归一格式、解析已确认别名，再按稳定梗 ID 与 BV 聚合。至少 2 个不同 BV 和现有播放量门槛保留。
- Unicode NFKC 统一全半角，英文匹配忽略大小写；去首尾空格、压缩连续空白。中文汉字之间的装饰空格可以去除，英文词间空格和有意义的标点保留。
- 版本化 JSON 别名表为每个已确认梗保存 id/name/aliases。初始仅使用本次方案中的 哈基米 / Hachimi / 哈 基 米 映射，不自动扩展其他语义别名。
- 未配置的新词继续自动发现，使用归一匹配键生成稳定 auto ID。未知词展示名从本轮原写法中确定性选择。
- 同 BV 多个别名只贡献一次播放量、互动量、视频数和趋势分；不同别名分布于两个 BV 可以共同满足门槛。
- 别名配置禁止一个归一写法指向多个 ID、重复 ID 和空字段，避免静默误合并。
- 不通过包含关系或相似度合并不同梗；移除当前末尾的字符串包含去重。
- 词表与种子豁免按同一别名身份解释，但种子不豁免两个 BV 门槛。保留普通噪声和不完整词过滤。
- API 输出规范名称、meme_id、接受的写法及每个关联视频的命中写法；保留原始标题。公开页投影显式保留这些公开字段并限制长度/数量。

## 边界与验证

不改变素材库，不迁移或覆盖数据库、收藏、线上词表及历史快照，不部署。别名表作为代码配置随版本发布，本轮不新增后台编辑界面。

验证格式变体、跨别名多视频、同视频不重复、未知词发现、英文边界、包含名称不误合并、配置冲突、归一后的噪声过滤及公开字段投影。用失败测试复现，再实现并运行相邻回归和独立审查。
