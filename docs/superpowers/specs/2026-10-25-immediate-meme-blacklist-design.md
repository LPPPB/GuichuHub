# 黑名单立即生效

用户要求：添加黑名单后立即生效，无需等下一轮抓取。

读取时对热梗和梗素材快照应用当前停用词表，按完整词及已配置别名匹配；显式停用优先于种子收录。保留原始快照，不删除历史、收藏、词表或观测点，撤销停用可恢复仍在当前快照中的条目。

后台保存成功触发当前页面重新读取；其他已打开页面通过现有 15 秒状态轮询感知规则版本。新 API 请求立即应用规则。公开首页、热梗、梗素材页在响应前校验并刷新，不能用一分钟缓存继续展示被屏蔽词；全被屏蔽时发布明确空榜。

取舍：采用读取过滤，避免直接删除快照导致撤销无法恢复，也避免重新抓取的耗时与上游依赖。不引入推送服务，已打开的其他访客页面最多等待一次现有状态轮询。

生产以实际镜像为基线制作增量包，不把 PR22 或其他分支功能整体带回；本轮先完成可审查代码、测试与发布范围。
