# V2 到 V3 迁移

V2 原目录及其审计副本保持本地、不可推送。V3 采用新的 Git 根历史，不导入 V2 的运行态文件或历史 blob。

迁移时只复制经过审查的业务数据：在停机窗口创建 V2 数据库的 SQLite 一致性备份，验证后由人工将副本放入 V3 的外部 `data/db`、`data/auth`。Cookie、token、日志、浏览器会话和旧备份不自动迁移；采集 Cookie 应通过 V3 的受控登录流程重新建立。

切换前保留 V2 可运行和 V3 数据备份。切换后验证 `/api/health`、看板数据与管理员登录；需要回退时仅回退代码/路由，任何数据库恢复都需单独确认。
