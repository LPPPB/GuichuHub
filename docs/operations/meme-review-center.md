# 梗库审核中心运行说明

热梗库和梗素材库保持自动更新，管理员在开发者后台的「梗库审核」中集中处理每日待办。词典身份和别名共用，榜单隐藏、补录与位置独立保存。

## 管理流程

1. 在「今日待办」切换热梗库或梗素材库。右侧备选区可搜索，词条的更多操作里可以查看关联 BV 或加入采集种子词。
2. 将备选词拖进选择区，或点按加号，词条按热度插入。可拖动已选词或点按上下箭头调序。满额时，加入新词会将最后一项移回备选区。保存草稿后自动更新继续运行。
3. 点击「预览调整」，确认两库结果后发布。到期时间从发布成功起计算 24 小时。自动采集、读取和同一请求重试均不续期。
4. 无需改动时，先预览再标记本期已审核。仅推进实际预览过的期次，新期次到达会使旧预览返回 409。
5. 当前调整可逐条撤销、单独续期，或预览撤销最近一次发布、某个库最近的调整、最近适用的词典操作。后来发生冲突时，使用显式编辑或拆分纠正。

人工补录可以关联已经采集登记的 BV。缺少当前观测时显示「人工收录」和空指标。合并身份按 BV 去重，使用原有评分和素材库标签优先分配规则重新计算；历史发布保持原样。旧 ID 保留重定向，拆出的新身份使用新 ID。

旧卡片启动时作为历史来源保留，标记证据不完整；完整证据采集到来之前，不允许从这些卡片推算合并热度。

## 采集种子词

原词汇规则中心的种子词入口跳转到审核中心。种子词单独点击「保存采集设置」，下次全量抓取生效。每轮固定读取的种子版本及词典版本，别名编辑不修改实际搜索字符串。

默认配置、自定义列表和显式空列表保留各自含义。空列表停止主动搜索，标签和标题仍可自然发现。命中停用规则的搜索词会提示冲突，公开两库仍优先隐藏该身份。

`GET /api/config/meme-seed-words` 返回 `version`；PUT 必须携带该版本，缺失返回 428，版本变化返回 409。旧浏览器页面需刷新到新界面后保存。

## 部署与回滚

先应用新增迁移 `0005_meme_review`。迁移仅创建五张 `app.meme_review_*` 表，分别存储当前控制状态、原始期次、草稿、发布与操作记录，并授予 API、Worker 和备份角色所需权限。

`MEME_REVIEW_MODE=shadow` 为默认值：采集和审核发布在后台运行，公开榜单沿用旧入口。验证完成后，将 API 与 Worker 设置为 `active`，公开 API、首页与独立 HTML 统一读取发布结果。

读取端和每分钟任务共同处理到期；HTML 每次响应前核对生成结果，跨库更新作为同一个批次提交，到期生成失败返回 503。

生产可能包含 Git 基线之外的修复。`ops/meme_review/prepare_legacy_overlay.py` 只在独立候选目录替换指纹匹配的函数，并保留原镜像其他源码。候选必须先运行 `ops/meme_review/accept_candidate.py`，连接隔离的 `reviewtest` 数据库。

切换前保留当前四个服务镜像、Compose 来源以及服务器内的备份，并在隔离数据库演练恢复和迁移。API 与 Worker 使用各自原有 Compose 文件链，逐服务执行 `up -d --no-deps --no-build`。

回滚使用旧功能代码加上迁移 0005 文件的专用兼容镜像，使 readiness 的版本检查与数据库保持一致；前端和 HTML 服务恢复上一个匹配的镜像对。新增表保留，避免在回滚过程中删除审核记录或降级数据库。

## 清理

首版调度器只统计，后台「当前调整」中查看预估；没有公开删除开关。

| 对象 | 到期起点与保留期 |
| --- | --- |
| 草稿 | 最后一次人工编辑后 14 天 |
| 原始期次证据 | 完成后 30 天，仍被引用则保留 |
| 已替换发布 | 替换后 90 天 |
| 人工操作 | 到期或撤销后的保留窗口；词典纠正与重定向记录长期保留 |

当前发布、最近两份回滚版本、最新有效来源、有效草稿和可撤销操作引用的期次受保护。未来启用分批删除时，删除事务重新取得同一控制锁并核查引用，每批最多 500 条。共享视频、观测、收藏、Cookie、令牌和种子词均不在清理查询范围内。

正式启用删除仍需单独核对待删范围及可恢复备份。
